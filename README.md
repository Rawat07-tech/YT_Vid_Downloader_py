# 🎥 YouTube Video Downloader (GUI Based)

A professional and user-friendly YouTube video downloader built with **Python**. This application allows users to download videos in high quality by simply pasting the URL and selecting a destination folder.

## ✨ Features
* **Simple GUI:** Built using Tkinter for a smooth user experience.
* **Folder Selection:** Users can choose where to save their videos.
* **High Quality:** Downloads the highest resolution available.
* **Reliable Engine:** Powered by `yt-dlp` to ensure fast and error-free downloads.

## 🛠️ Technologies Used
* **Python 3.x**
* **Tkinter** (for GUI)
* **yt-dlp** (for video processing)
